# 퀴즈메이트 — 노트에서 문제와 오답 복습까지

노션 페이지나 샘플 노트로 객관식·단답형 문제를 만들고, 풀이 후 점수·정답·해설·원문 출처를 확인하는 학습 웹앱입니다.

## 해결하려던 문제

노트를 읽는 것만으로는 어떤 개념을 이해했는지 확인하기 어렵습니다. 학습 자료를 문제로 바꾸고, 틀린 문제에서 원문과 해설로 돌아갈 수 있는 흐름을 구성했습니다.

## 사용자 흐름

1. 샘플 노트 또는 노션 페이지를 선택합니다.
2. 객관식·단답형, 난이도와 문제 수를 설정합니다.
3. 문제를 풀고 답안을 제출합니다.
4. 점수·오답·정답·해설과 원문 출처를 확인합니다.

## 설계와 구현

- **규칙 기반 문제 생성:** 원문 문장과 핵심어를 이용해 문제·선택지·해설을 구성합니다. 생성형 AI 호출 비용 없이 샘플 자료를 체험할 수 있습니다.
- **API 책임 분리:** 노션 자료 읽기와 문제 생성을 분리해 자료 수집과 출제 방식을 각각 바꿀 수 있도록 구성했습니다.
- **자료 접근 보호:** 노션 토큰은 서버 환경에 보관하고 클라이언트로 전달하지 않습니다.
- **학습 결과 연결:** 풀이 상태·채점·오답 해설을 하나의 화면 흐름으로 연결합니다.

| 경로 | 역할 |
| --- | --- |
| `app/page.tsx` | React·TypeScript 설정·풀이·결과 화면 |
| `app/api/notion/page/route.ts` | 노션 페이지 읽기 |
| `app/api/quiz/generate/route.ts` | 원문 기반 문제 생성 |
| `app/globals.css` | 반응형 화면 스타일 |
| `worker/index.ts` | Cloudflare Worker 실행 진입점 |

vinext·Vite·Tailwind CSS를 사용합니다. 현재 출제기는 규칙 기반이며 LLM이 문제를 생성하는 앱으로 소개하지 않습니다. 원문의 구성과 문장에 따라 문제 품질이 달라질 수 있습니다.

## 검증

프로덕션 빌드와 초기 설정 화면 서버 렌더링 테스트를 제공합니다. 실제 노션 연결과 브라우저의 전체 풀이 흐름은 별도 검증 범위입니다. [검증 기록](docs/PUBLIC_VALIDATION.md)에서 확인할 수 있습니다.

## 실행

Node.js 22.13 이상을 사용합니다.

```bash
git clone https://github.com/choisung-ho/quizmate.git
cd quizmate
npm ci
cp .env.example .env.local
npm run dev
```

샘플 노트는 노션 연결 없이 사용할 수 있습니다. 실제 페이지를 읽으려면 `.env.local`의 `NOTION_TOKEN`에 본인의 통합 토큰을 넣고 노션 페이지를 해당 통합에 공유합니다.

```bash
npm test
```

## 배포 구성

Cloudflare Worker용 실행 진입점을 제공합니다. D1 데이터베이스를 사용하려면 Worker 환경에 `DB` 바인딩을 설정합니다. `app/chatgpt-auth.ts`의 로그인 도우미는 Sites 인증 헤더에 의존하는 선택적 구성입니다. 일반 로컬 실행에서 ChatGPT 로그인 기능을 제공하지는 않습니다.

실제 노션 토큰·개인 노트·로컬 캐시·빌드 결과물은 소스에서 제외합니다.
